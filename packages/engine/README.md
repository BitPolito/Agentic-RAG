# agentic-rag

`agentic-rag` is the domain-agnostic RAG engine, imported as `agentic_rag`. It provides:

- core types;
- ports defined as `typing.Protocol`;
- ingestion and retrieval pipelines;
- the citation-bearing evidence pack;
- evaluation metrics;
- optional backend adapters, installed as extras.

The architecture is described in `docs/specs/2026-10-16-agentic-rag-design.md` (section 5).
