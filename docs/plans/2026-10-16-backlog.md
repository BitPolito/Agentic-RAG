# Agentic-RAG Backlog

- **Spec:** `docs/specs/2026-10-16-agentic-rag-design.md`
- **Academy source pin:** `BitPolito/bitcoin-academy@b78d661`. Every porting issue copies code from this commit, and paths are relative to `services/ai/`.
- **Planning model: rolling wave.**
  - Milestones M0, M1, M2, E1 and R1 are broken down into issues that are ready to be picked up.
  - Later milestones are tracked as one epic issue each, with a sub-issue list.
  - An epic's sub-issues are written in full when its predecessor milestone closes, using what was learned by then. Each epic contains the task "Detail the sub-issues of this epic".

## How to read an issue entry

Each `### <ID> · <title>` entry becomes one GitHub issue.

- **Labels:** the labels to apply. Every entry also gets its milestone's `track/*` label.
- **Blocked by:** backlog IDs that must close first. The `Blocked by #n` lines in the issue body are filled in when the issues are created.
- **Body:** the issue template sections:
  - Goal
  - Scope
  - Out of scope
  - Files
  - Acceptance criteria
  - How to verify

A Definition of Ready applies to every issue: the acceptance criteria are testable, the blockers are closed, and the size is L or smaller.

### M1-2 · Core types
- **Labels:** type/feature, area/ingest, priority/p0, size/M, agent-ready
- **Blocked by:** M0-2

**Goal:** Implement the domain-neutral data model in `agentic_rag.types`.

**Scope:** frozen Pydantic v2 models.

- `Namespace`, a validated slug matching `^[a-z0-9][a-z0-9_-]{0,63}$`.
- `BlockKind`, an enum: heading, paragraph, table, formula, code, list, figure_caption.
- `Block`, with kind, text, level, page and slide.
- `Document`, with id, namespace, source_name, mime_type, blocks and metadata. Port it from Academy's `schemas/normalized_document.py`, dropping the course and exam fields.

- `Chunk`, with id, parent_id (an explicit field: never derive it from the id), doc_id, namespace, text, kind, section, page, slide and token_count.
- `SectionNode`, with title, level, children and parent_ids.
- `IngestResult`, with doc_id, parents, chunks, section_tree, stats and warnings.

**Files:** `packages/engine/src/agentic_rag/types/{__init__,document,chunk,ingest}.py` and `packages/engine/tests/types/`.

**Acceptance criteria:**
- [ ] Invalid namespaces are rejected. Tested cases: an empty string, uppercase letters, a slash, and 65 characters.
- [ ] A `Chunk` cannot be built without a `parent_id`.
- [ ] Every model round-trips through `model_dump_json` / `model_validate_json`.
- [ ] mypy passes in strict mode.

**How to verify:** `uv run pytest packages/engine/tests/types -q && uv run mypy`
